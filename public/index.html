Install as an app

iPhone / iPad: open this page in Safari, tap Share, then Add to Home Screen. Android (Chrome): menu, then Add to Home screen or Install app. Computer: Chrome or Edge menu, then Install or Create shortcut. It opens full screen like an app. Turn the phone sideways for the best view while playing, and use the Fullscreen button in a game.

Add your own game

Every game is one self-contained registerGame() block. The lobby, input mapping, countdowns, rounds, scoring and pause screen are handled for you, so a new game only describes its rules and how it draws.

registerGame({
  id: 'my-game', title: 'My Game', blurb: 'One line pitch.',
  kind: 'live',             // 'live' = simultaneous, 'turns' = hot-seat
  min: 2, max: 4, color: 0, // player range, cover colour 0-3
  help: 'Move with stick or keys, A to act.',
  icon() { return '<svg viewBox="0 0 200 125">...</svg>'; },
  create(api) {
    // api.players[i] {name, color}, api.n, api.input(i), api.turn(i),
    // api.endRound(winnerIndex | -1, message), api.beep(name)
    return {
      reset(roundIndex) { /* fresh round */ },
      update(dt) { /* input: x, y, a, b, plus pa/pb/pu/pd/pl/pr = just pressed */ },
      draw(g) { /* 960 x 600 canvas context */ },
      pointer(x, y, type) { /* optional: 'move' or 'down' */ }
    };
  }
});
